# libSceNpWebApi2 technical debt

### Silent stubs

- [sceNpWebApi2SetRequestTimeout](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2) - the `(request id, timeout)` signature follows [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/np/np_web_api2/np_web_api2.cpp). Pinball FX (PPSA08755) calls it while its main menu loads. It returns `INVALID_ARGUMENT` for a request id of 0 or below and otherwise succeeds and stores nothing: no request reaches a service, as `sceNpWebApi2SendRequest` fails with `UNAVAILABLE` at once, so no timeout can expire. shadPS4 returns `LIB_CONTEXT_NOT_FOUND`, `USER_CONTEXT_NOT_FOUND` or `REQUEST_NOT_FOUND` for an id it does not know; this call does not look the id up among the requests `sceNpWebApi2CreateRequest` records for `sceNpWebApi2AddWebTraceTag` (`sceNpWebApi2AbortRequest`, `sceNpWebApi2AddHttpRequestHeader` and `sceNpWebApi2DeleteRequest` also accept any id), so those errors are not reported

- [sceNpWebApi2AddWebTraceTag](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2) - the `(int64 requestId, const char* value)` signature follows the SDK 12.000 reference, which lists no specific errors. Requests created by `sceNpWebApi2CreateRequest` are now tracked until `sceNpWebApi2DeleteRequest`: a null value returns `INVALID_ARGUMENT` (0x80553402) and an id that was never created or was deleted `REQUEST_NOT_FOUND` (0x80553406, the reference's code; the library's `UNAVAILABLE` constant has the same value). The tags are kept with the request in call order and never sent, since no request reaches PSN; the WebTrace debug setting that consumes them is a devkit feature. A tag length limit (`PARAMETER_TOO_LONG`) is not known, so any length is accepted
- [sceNpWebApi2PushEventAbortHandle](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2, NID `1OLgvahaSco`) - the two signed 32-bit handle arguments and return type follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/443f022450f6857256e780daa3d5a14029a748f7/src/core/libraries/np/np_web_api2/np_web_api2.cpp) (PS4); the PS5 signature and abort behavior are unverified. PPSA01736 imports it. Handles from `sceNpWebApi2PushEventCreateHandle` are tracked per library context: an unknown context returns `LIB_CONTEXT_NOT_FOUND`, a handle of another or a terminated context or a deleted handle returns `HANDLE_NOT_FOUND`, and an aborted handle makes `sceNpWebApi2PushEventCreateFilter` return `ABORTED`. Nothing else waits on a handle offline
- [sceNpWebApi2GetMemoryPoolStats](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2) - imported by PPSA21703's Unity PSN plugin. The signature `(int libCtxId, stats*)` and the layout of the Http2 statistics above (measured on a PS5 for Http2, Ssl and Net) are assumed for this library, not measured. The pool size is the one given to `sceNpWebApi2Initialize`, and the peak and current use are 0. The error codes are unknown, so a null output or an unknown context throws
- [sceNpWebApi2PushEventSetHandleTimeout](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2) - imported by PPSA01317, which fails to load without it. The signature `(int libCtxId, int handleId, uint32_t timeout)` follows `sceNpWebApiSetHandleTimeout` of the PS4 libSceNpWebApi in [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/np/np_web_api.cpp) and is unverified on the PS5. An unknown library context throws, as in `sceNpWebApi2GetMemoryPoolStats`, since its error code is unknown. The handle is not checked, as push event handles are not tracked (`sceNpWebApi2PushEventDeleteHandle` accepts any handle), and the timeout is not kept, as nothing waits on a handle offline
