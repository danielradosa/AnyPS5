# libSceHmd2 technical debt

### Silent stubs

- [libSceHmd2](../../../core/libs/prx/libSceHmd2/Export.cpp) has no PS VR2 runtime: `sceHmd2Initialize` fails, so every other export answers as a library that was never initialized and writes nothing. `sceHmd2GetDeviceInformation`, `sceHmd2GetFieldOfView` and `sceHmd2GetFieldOfViewWithoutHandle` reject a null output with `PARAMETER_NULL` (0x81110008) first, as libSceHmd's getters do ([shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/hmd/hmd.cpp)); everything else returns `NOT_INITIALIZED` (0x81110002). PPSA01317 skips its whole VR set-up when initialization fails. That set-up imports the reprojection buffer size queries and `sceVrTracker2QueryMemory` of [libSceVrTracker2](../../../core/libs/prx/libSceVrTracker2/Export.cpp), whose console values are unknown, so initialization cannot succeed as it would on a console without a headset. The five size queries (`sceHmd2ReprojectionQueryBufferSizeAlign`, `sceHmd2ReprojectionQueryDisplayBufferSizeAlign`, `sceHmd2ReprojectionQuerySeeThroughBufferSizeAlign`, `sceHmd2ReprojectionGetMirroringWorkMemorySizeAlign` and `sceHmd2ReprojectionGetMirroringDisplayBufferSizeAlign`) return a 16-byte `{size, align}` pair by value, in RAX and RDX, as [PS5VR](https://github.com/theghostonline/PS5VR/blob/0e408909ce7a39891a2e06eee3438d07a09e11e3/app/src/app_vr.c#L27-L45) and [KytyPS5](https://github.com/KytyPS5/KytyPS5/blob/df5b9b92be7dfd463b47756b707d6d356a9f0550/src/libs/libHmd2.cpp#L160-L171) declare them, and throw: the pair has no error result, PS5VR calls them only after `sceHmd2Initialize` succeeds ([L483-L487](https://github.com/theghostonline/PS5VR/blob/0e408909ce7a39891a2e06eee3438d07a09e11e3/app/src/app_vr.c#L483-L487), [L645-L646](https://github.com/theghostonline/PS5VR/blob/0e408909ce7a39891a2e06eee3438d07a09e11e3/app/src/app_vr.c#L645-L646)) and logs the values without publishing them, and KytyPS5 answers without an initialization check with the size of its own reprojection state and render target, so the console's answer for a library that was never initialized is unknown
- [libSceHmd2](../../../core/libs/prx/libSceHmd2/Export.cpp) has no PS VR2 runtime: `sceHmd2Initialize` returns libSceHmd's `UNSUPPORTED_FEATURE` (0x81110016) for any param, so the other calls answer as before initialization and `sceHmd2Open` returns `NotInitialized` (0x8a720002). These results are restored from the behaviour before #7323 and are not measured on hardware: firmware 13.20's libSceHmd2, with the `/dev/hmd2_cmd` state measured on a retail PS5 with no headset connected (connected flag 0, status 2, user -1), initializes, returns a handle from `sceHmd2Open` and reports `NotDetected`, which the code past the initialization check models but no title reaches. PPSA01317 passes a pointer to 16 zeroed bytes, only tests the result for non-zero and then skips its VR set-up; with initialization succeeding it stopped on `sceHmd2ReprojectionQueryBufferSizeAlign` (#6350). That export, `sceHmd2ReprojectionQueryDisplayBufferSizeAlign` and `sceHmd2ReprojectionQuerySeeThroughBufferSizeAlign` stay unimplemented and throw pending console measurements of their sizes and alignments. The other reprojection and gaze exports and every [libSceVrTracker2](../../../core/libs/prx/libSceVrTracker2/Export.cpp) export throw

### Unknown function info

- [sceHmd2ReprojectionQuerySeeThroughBufferSizeAlign](../../../core/libs/prx/libSceHmd2/Export.cpp) (libSceHmd2) - imported by PPSA29866 and added without an implementation because the title fails to load without it. No source declares it: the `{size, align}` result without parameters is inferred from the four other size queries and from the see-through buffer pointer at 0x28 of [KytyPS5](https://github.com/KytyPS5/KytyPS5/blob/df5b9b92be7dfd463b47756b707d6d356a9f0550/src/libs/libHmd2.cpp#L59-L70)'s `sceHmd2ReprojectionInitialize` parameter, which KytyPS5 does not support
- [libSceHmd2](../../../core/libs/prx/libSceHmd2/Export.cpp) signatures follow [PS5VR](https://github.com/theghostonline/PS5VR/blob/0e408909ce7a39891a2e06eee3438d07a09e11e3/app/src/app_vr.c#L29-L57) (PPSA99177), which drives PS VR2 on FW 13.60: `sceHmd2Open(userId, type, index, param)`, `sceHmd2Close(handle)`, `sceHmd2GetDeviceInformation(info)`, `sceHmd2GetFieldOfViewWithoutHandle(fieldOfView)`, `sceHmd2SetVibration(handle, strength)`, `sceHmd2GazeGetResult(param, result)`, `sceHmd2ReprojectionInitialize(param, reserved)`, `sceHmd2ReprojectionEnableVrMode(mode)`, `sceHmd2ReprojectionBeginFrame(frame)`, `sceHmd2ReprojectionGetPredictedDisplayTime(frame, time)`, `sceHmd2ReprojectionSetParam(buffer, frame, param, trace)`, `sceHmd2ReprojectionSetRenderConfig(halfRate, reserved0, reserved1)`, `sceHmd2ReprojectionSetMirroringOption(option)`, `sceHmd2ReprojectionEnableMirroring(param)`, and `sceHmd2Terminate`, `sceHmd2ReprojectionDisableVrMode`, `sceHmd2ReprojectionDisableMirroring` and `sceHmd2ReprojectionTerminate` without parameters. `sceHmd2GetDeviceInformationByHandle(handle, info)` and `sceHmd2GetFieldOfView(handle, fieldOfView)` follow libSceHmd. `sceHmd2GazeGetResultForFoveatedRendering`, `sceHmd2ReprojectionSetAllowPositionalReprojection`, `sceHmd2ReprojectionSetParamWithBuffer` and `sceHmd2ReprojectionSetTiming` are declared without parameters and read none; whether the console checks any argument before initialization is unknown. PPSA01317 imports most of them; names from the aerolib NID list
- [libSceHmd2](../../../core/libs/prx/libSceHmd2/Export.cpp) error codes are libSceHmd's (0x8111xxxx). PS5VR retries `sceHmd2ReprojectionBeginFrame` while it returns [0x8A72001A](https://github.com/theghostonline/PS5VR/blob/0e408909ce7a39891a2e06eee3438d07a09e11e3/app/src/app_vr.c#L911-L916) (queue full), and the headset camera devices answer it [0x8A721003](https://github.com/theghostonline/PS5VR/blob/0e408909ce7a39891a2e06eee3438d07a09e11e3/app/src/vr_system.c#L214-L216), so the console's codes are likely 0x8A72xxxx. [KytyPS5](https://github.com/KytyPS5/KytyPS5/blob/df5b9b92be7dfd463b47756b707d6d356a9f0550/src/libs/libHmd2.cpp#L22-L26) uses 0x8A720002 for an uninitialized library and 0x8A720008 for a null parameter, and its getters check initialization before a null output ([L117-L151](https://github.com/KytyPS5/KytyPS5/blob/df5b9b92be7dfd463b47756b707d6d356a9f0550/src/libs/libHmd2.cpp#L117-L151)); neither is confirmed by a console or a title
