SDK-dependent peer-address validation and local-network discovery remain incomplete.
- [sceNpSessionSignalingGetGroupFromSessionId](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - imported by PPSA07411. The `(context id, const char* session id, group id*)` signature and the `NOT_INITIALIZED`, `INVALID_ARGUMENT` (null session id or output) and `CTX_NOT_FOUND` checks, in that order, follow the SDK 12.000 reference.
