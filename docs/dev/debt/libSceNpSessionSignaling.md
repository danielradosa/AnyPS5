# libSceNpSessionSignaling technical debt

### Unknown function info

- [sceNpSessionSignalingGetGroupFromSessionId](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - imported by PPSA07411. The `(context id, const char* session id, group id*)` signature and the `NOT_INITIALIZED`, `INVALID_ARGUMENT` (null session id or output) and `CTX_NOT_FOUND` checks, in that order, follow the SDK 12.000 reference. A group exists only for a session activated with `sceNpSessionSignalingActivateSession`, which never succeeds offline, so every lookup in a live context answers `GRP_NOT_FOUND` (0x8055330A, the reference's error for a missing group in `sceNpSessionSignalingGetGroupInfo`) without writing the group id; the reference lists no error for an unknown session, so the console's code for it is unverified
- [sceNpSessionSignalingGetConnectionStatus](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - `(int32 context id, int32 connection id, int32* status, SceNetInAddr* peer address, uint16* peer port)` is ASTRO BOT's (PPSA21564 01.007.000) call at 0x30622B: the context id from a 32-bit field, the connection id, three stack outputs, a negative result taken as an error, then the address passed to `sceNetInetNtop(AF_INET, ...)` and the port to `sceNetNtohs`. It matches PS4's `sceNpSignalingGetConnectionStatus`. The title reaches it only for a connection id from the signaling library, which offline never hands one out. No session ever activates offline, so every connection id answers `CONN_NOT_FOUND` (0x8055330C, from [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/64d198190fa05d37cbb1fa29c50f967c376fce55/src/core/libraries/np/np_error.h)) without writing the outputs, and a null status answers `INVALID_ARGUMENT`. An unknown context answers `CTX_NOT_FOUND`. The SDK 12.000 reference also describes status `INACTIVE` (0) for a connection id that does not exist, so the console may return 0 with `INACTIVE` instead. The console's answer for an unknown context or connection is unverified
