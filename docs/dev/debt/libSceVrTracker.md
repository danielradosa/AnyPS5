# libSceVrTracker technical debt

### Silent stubs

- [sceVrTrackerInit, sceVrTrackerGetTime, sceVrTrackerGpuSubmit, sceVrTrackerGpuWait](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - prototypes from [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json); layouts, memory sizes (onion 4 MiB, 8 with automatic Move calibration, garlic 48, work 16, 64 KiB aligned), pipe and queue limits (7 and 8) and error codes follow the PS4 library in [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/vr_tracker/vr_tracker.cpp). Init checks the parameter like shadPS4 but not that each region is mapped, and does not touch the memory; a null parameter answers `ARGUMENT_INVALID` (shadPS4 reads it unchecked). GetTime is the process time. As libSceCamera never streams, GpuSubmit answers `ARGUMENT_INVALID` unread and GpuWait `NOT_EXECUTE_GPU_SUBMIT`, as in shadPS4. No PS5 title using it has been run
- [sceVrTrackerQueryMemory, sceVrTrackerRecalibrate, sceVrTrackerSetDurationUntilStatusNotTracking and sceVrTrackerGpuWaitAndCpuProcess](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - prototypes from [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json), answers and the query (64 bytes), result (64) and recalibrate (32) layouts from [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/vr_tracker/vr_tracker.cpp), not measured on a PS5. QueryMemory works without Init, checks the size, profile (0 or 100) and calibration like Init and reports Init's sizes. Recalibrate answers `DEVICE_NOT_REGISTERED` for the HMD (no headset) and for a type nothing registered, else 0 without recalibrating. SetDurationUntilStatusNotTracking only checks the type; GpuWaitAndCpuProcess answers `NOT_EXECUTE_GPU_SUBMIT` like GpuWait
- [sceVrTrackerRegisterDevice, sceVrTrackerRegisterDevice2, sceVrTrackerRegisterDeviceInternal, sceVrTrackerUnregisterDevice and sceVrTrackerTerm](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - prototypes from orbital (RegisterDeviceInternal's two extra `int32_t` from shadPS4), answers from shadPS4, not measured on a PS5. One handle is kept per device type (HMD, DualShock 4, Move, gun) without checking it against those libraries, as shadPS4 does: a type above 3 or an Internal mode above 4 is `ARGUMENT_INVALID`, a type already taken `DEVICE_ALREADY_REGISTERED`; RegisterDevice and RegisterDevice2 pass mode -1. Unregister frees the first type holding the handle, else `ARGUMENT_INVALID`. Term ends the library and, unlike shadPS4, also forgets the registered handles
