# libSceBluetoothHid technical debt

### Silent stubs

- [libSceBluetoothHid](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) implements only the no-device path: initialization and callback and device registration succeed, the callback is never called because no device connects, and calls that need a connected device (`sceBluetoothHidGetDeviceName`, `sceBluetoothHidGetDeviceInfo`, `sceBluetoothHidGetReportDescriptor`, `sceBluetoothHidGetInputReport`, `sceBluetoothHidGetFeatureReport`, `sceBluetoothHidSetOutputReport`, `sceBluetoothHidSetFeatureReport`, `sceBluetoothHidInterruptOutput`, `sceBluetoothHidDisconnectDevice`) throw

### Unknown function info

- [libSceBluetoothHid](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - signatures taken from PPSA01317: `sceBluetoothHidInit()` and `sceBluetoothHidUnregisterCallback()` without arguments, `sceBluetoothHidRegisterCallback(callback, 0, param)` with a 16-byte param, and `sceBluetoothHidRegisterDevice` / `sceBluetoothHidUnregisterDevice(vendorId, productId)`. The device and report calls follow [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L74-L108), which gives only the argument shapes: `GetReportDescriptor(handle, buffer, length)`, `GetDeviceName(handle, name)`, `GetDeviceInfo(deviceId, info)`, `GetInputReport(report, reportId)` and `GetFeatureReport(report, reportId)`, whose calls take no handle, `SetOutputReport`, `SetFeatureReport` and `InterruptOutput(handle, reportId, data, length)`, and `DisconnectDevice(deviceId)`. The name buffer size and encoding, the info and report block layouts, and the error codes, only known to be in the 0x8154xxxx range ([L11-L12](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L11-L12)), are unknown. No device ever connects, so every handle and device id is unknown and these calls throw without reading or writing caller memory
- [sceBluetoothHidParamInitialize](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - the `(param, uint64_t value)` signature and the block layout follow [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L21-L49): the value is stored at offset 0 and the 32-bit word at offset 8 is cleared, twelve bytes of the 16-byte block. It returns 0; a null param throws because the console's error code is unknown, and initialization is not checked, as for the other calls
- [sceBluetoothHidThreadParamInitialize](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L51-L53) gives `(uint32_t* param, uint32_t value1, uint64_t value2)`, but not where the two values land in the block, so it stays a throwing stub declared without parameters
- [sceBluetoothHidDebugGetVersion](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L110-L112) gives `int32_t (void)` returning the module's build version, whose value is unknown, so it stays a throwing stub
