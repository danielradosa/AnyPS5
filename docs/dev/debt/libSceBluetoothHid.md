# libSceBluetoothHid technical debt

### Silent stubs

- [libSceBluetoothHid](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) implements only the no-device path: initialization and callback and device registration succeed, the callback is never called because no device connects, and calls that need a connected device (`sceBluetoothHidGetDeviceName`, `sceBluetoothHidGetInputReport`, `sceBluetoothHidSetOutputReport`) throw

### Unknown function info

- [libSceBluetoothHid](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - signatures taken from PPSA01317: `sceBluetoothHidInit()` and `sceBluetoothHidUnregisterCallback()` without arguments, `sceBluetoothHidRegisterCallback(callback, 0, param)` with a 16-byte param, and `sceBluetoothHidRegisterDevice` / `sceBluetoothHidUnregisterDevice(vendorId, productId)`. `sceBluetoothHidGetDeviceName(handle, name)`, `sceBluetoothHidGetInputReport(report, reportId)` and `sceBluetoothHidSetOutputReport(handle, reportId, data, length)` follow [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L80-L96), which gives only the argument shapes: the name buffer size and encoding, the layout of the input report block, whose call takes no handle, and the error codes, only known to be in the 0x8154xxxx range ([L11-L12](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L11-L12)), are unknown. No device ever connects, so every handle is unknown and the three calls throw without reading or writing caller memory
