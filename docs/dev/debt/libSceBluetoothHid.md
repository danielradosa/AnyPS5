# libSceBluetoothHid technical debt

### Silent stubs

- [libSceBluetoothHid](../../../core/libs/prx/libSceBluetoothHid/Export.cpp): the host still has no device backend or event worker. Registration retains only lifecycle state and never delivers the recovered 104-byte callback events. Custom worker scheduling throws; device ioctl failures and resource exhaustion are not modeled. No device ever connects, so calls that need a connected device (`sceBluetoothHidGetDeviceName`, `sceBluetoothHidGetDeviceInfo`, `sceBluetoothHidGetReportDescriptor`, `sceBluetoothHidGetInputReport`, `sceBluetoothHidGetFeatureReport`, `sceBluetoothHidSetOutputReport`, `sceBluetoothHidSetFeatureReport`, `sceBluetoothHidInterruptOutput`, `sceBluetoothHidDisconnectDevice`) throw without reading or writing caller memory

### Unknown function info

- [sceBluetoothHidGetDeviceName and sceBluetoothHidGetDeviceInfo](../../../core/libs/prx/libSceBluetoothHid/Export.cpp): output pointers are forwarded to device ioctls without accessing the buffers. Their output sizes and layouts remain unresolved. Report APIs use 64-bit device handles; device-info and disconnect APIs use 32-bit device IDs.
- [sceBluetoothHidParamInitialize](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - following [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L21-L49), it stores the thread param pointer at offset 0 and clears the 32-bit word at offset 8, twelve bytes of the 16-byte block, and returns 0; a null param throws because the console's error code is unknown, and initialization is not checked
- [sceBluetoothHidThreadParamInitialize](../../../core/libs/prx/libSceBluetoothHid/Export.cpp) (libSceBluetoothHid) - [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Bluetooth/SceBluetoothHid.cs#L51-L53) gives `(param, value1, value2)` and the recovered signature `(param, priority, affinityMask)`, but which fields of the block it writes is unconfirmed, so it stays a throwing stub
- [sceBluetoothHidDebugGetVersion](../../../core/libs/prx/libSceBluetoothHid/Export.cpp): returns a constant without reading arguments, so the supplied implementation does not establish whether the public prototype has unused parameters.
