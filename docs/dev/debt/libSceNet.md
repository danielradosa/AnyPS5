# libSceNet technical debt

### Silent stubs

- [sceNetShowRoute, sceNetShowRoute6, sceNetShowPolicy, sceNetShowNetstatEx](../../../core/libs/prx/libSceNet/Export.cpp) (libSceNet) - return success without printing anything: the `()` signatures and the success return follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/network/net.cpp), which stubs them the same way. A route report would follow FreeBSD `netstat -rn` as `sceNetShowIfconfig` follows `ifconfig`, but libSceNet does not read the host routing table, nothing here models a network policy, and `sceNetShowNetstatEx` does not print the `sceNetShowNetstat` report. What the console prints and where is unverified
- [sceNetShowRouteWithMemory, sceNetShowRoute6WithMemory](../../../core/libs/prx/libSceNet/Export.cpp) (libSceNet) - validates memory pool ID and returns success without printing anything: the `(int memid)` signature and pool validation follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/net/net.cpp) and `sceNetShowNetstatWithMemory`. What the console prints and where is unverified `sceNetShowRoute6WithMemory` takes the same `(int memid)` in [shadPS4 23c41333](https://github.com/shadps4-emu/shadPS4/blob/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/net/net.cpp), which also validates the pool and prints nothing, and it answers exactly like `sceNetShowRouteWithMemory`, as `sceNetShowRoute6` answers like `sceNetShowRoute`.

FreeBSD 11.4's [ip(4)](https://man.freebsd.org/cgi/man.cgi?manpath=FreeBSD+11.4-RELEASE&query=ip&sektion=4) documents the like-named `IPPROTO_IP` option `IP_ONESBCAST`: a datagram sent to an interface's directed broadcast address, such as 192.168.2.255, leaves through that interface with its destination rewritten to 255.255.255.255, and only on a socket allowed to set `SO_BROADCAST`. The per-call behavior follows FreeBSD 11.4's `soreceive_generic` and `sosend_generic` (`sys/kern/uipc_socket.c`); `0x80` is FreeBSD's flag value (`sys/sys/socket.h`). On Windows native sockets stay non-blocking. `MSG_DONTWAIT` and guest `SO_NBIO` return one host transfer's result.
