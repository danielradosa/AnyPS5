# libSceContentExport technical debt

### Unknown function info

- [sceContentExportFromData](../../../core/libs/prx/libSceContentExport/Export.cpp) (libSceContentExport) - the signature is known (AlexAltea/orbital, SharpProspero). The data provider `int32_t (void** data, uint64_t* size, void* userData)` follows the typedef in [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/content_export/content_export.h) and SharpProspero's return values, 0 for more data and 1 for the last chunk; PPSA21567 passes a 0x400-byte path buffer and a provider that hands over the whole PNG in one chunk and returns 1. The provider runs on the caller's thread with no library lock held, and each chunk is appended to `/_ce/export_N.<ext>`. A content length of 0, a provider return other than 0 or 1, a chunk past the content length or with a null pointer, a return of 0 once the content length was already reached and a total that differs from the content length at the last chunk are unverified and throw after removing the partial file; the console's provider error code is unknown. `sceContentExportFromFile*` copy the file to `/_ce` in the host root and return that guest path; the title and comment of `ContentExportParam` are validated for termination but not stored, and the console's per-call error for a busy or full service (`BUSY`, `EXECUTION_MAX`) is unverified; a provider that returns 0 (more) with no data throws instead of being called again, since the console's handling is unknown
- PlayStation 5 firmware exports declared without parameters, signatures unknown: [sceContentExportAddToFavorites, sceContentExportDataProvideFunction, sceContentExportFree, sceContentExportFrom, sceContentExportFromFileForSf, sceContentExportFromFileWithContentIdList, sceContentExportFromFileWithTitleIdList, sceContentExportMalloc, sceContentExportRemoveFromFavorites, sceContentExportRenameContent, sceContentExportValidateContents](../../../core/libs/prx/libSceContentExport/Export.cpp) (libSceContentExport). Names from the firmware NID database; unimplemented and throw `NotImplemented_nid_no_patch`.
- [sceContentExportInit](../../../core/libs/prx/libSceContentExport/Export.cpp) (libSceContentExport) - the `(const initparam*)` prototype is [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json)'s; it takes the `sceContentExportInit2` parameter and checks it the same way except the reserved fields, as the PS4 functions in [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/content_export/content_export.cpp#L13-L36) do: there only `sceContentExportInit2` checks them. Like `sceContentExportInit2`, a null parameter, missing allocators or a second initialization throw instead of returning shadPS4's `INVALDPARAM` and `MULTIPLEINIT`, which are not measured on a PS5

### Functional

- [Content export sessions](../../../core/libs/prx/libSceContentExport/Export.cpp) (libSceContentExport): `sceContentExportStart` hands out positive session ids, at most 10 live, which `sceContentExportFinish` closes. The signatures follow [Orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json) and the limit `MaxExecution` [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Content/ContentExport.cs); the parameter layouts follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/443f022450f6857256e780daa3d5a14029a748f7/src/core/libraries/content_export/content_export.h). The host has no media library, so `sceContentExportFromDataWithThumbnail` throws once the session is checked, before calling either data callback. `sceContentExportGetProgress` and `sceContentExportCancel` throw for a live session, as their result with no running export is unknown. An eleventh `sceContentExportStart` and `sceContentExportTerm` with live sessions throw: whether the console answers `EXECUTION_MAX` or `BUSY` there, or ends the sessions, is unverified. Session id values and error precedence are unverified
