# libSceScreenShot technical debt

### Silent stubs

- [sceScreenShotDisableNotification, sceScreenShotEnableNotification, sceScreenShotSetParam](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - return 0 and change nothing: the notification and the photo parameters belong to system screenshots, which are never taken, as for the overlay image below. The `int32_t (void)` notification prototypes are [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/ScreenShot.h)'s and `sceScreenShotSetParam(const param*)` is [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json)'s; the parameter is not read, its layout and the errors for a null or malformed one are unknown
- [sceScreenShotIsVshScreenCaptureDisabled](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - returns 0, capture not disabled: no system software here disables screen capture. The `int32_t (void)` prototype is [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/ScreenShot.h)'s; that the result is a flag rather than an error code is read from the name, not measured
- [sceScreenShotSetOverlayImage and sceScreenShotSetOverlayImageWithOrigin](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - check the arguments and the file as the PS5 module does, then return 0 without keeping the image, since this project takes no screenshots to overlay
- [sceScreenShotIsDisabled](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - reports one process-wide flag set by sceScreenShotDisable and cleared by sceScreenShotEnable for any id other than -1; on the console the system software answers, and what the id selects is unknown

They are declared without parameters solely to resolve known imports; this is not an ABI claim, and every call throws
