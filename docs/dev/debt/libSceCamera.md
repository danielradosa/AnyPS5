# libSceCamera technical debt

### Functional

- [sceCameraIsAttached](../../../core/libs/prx/libSceCamera/Export.cpp) (libSceCamera) - no camera is ever attached: index 0 returns 0 (not attached) and any other index returns `SCE_CAMERA_ERROR_PARAM` (0x802E0000), as [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/9a8ae4417bbfc79b1a43eb8a2eb0bb602148261e/src/core/libraries/camera/camera.cpp#L187-L200) does without a configured camera, with the error value from its [camera_error.h](https://github.com/shadps4-emu/shadPS4/blob/9a8ae4417bbfc79b1a43eb8a2eb0bb602148261e/src/core/libraries/camera/camera_error.h). Not measured on a console. Closes when: a host camera is exposed to guests.
- [sceCameraOpen, sceCameraClose, sceCameraStart and sceCameraStop](../../../core/libs/prx/libSceCamera/Export.cpp) (libSceCamera) - prototypes from [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json), answers from [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/camera/camera.cpp) without a configured camera, not measured on a console. Open takes only the system user (255), type 0 and index 0 and, like shadPS4, succeeds without a camera, returning the count of open handles (1, 2, ...); Close counts down and any handle of 1 or more is accepted while one is open (no per-handle table). Start checks the 24-byte parameter and its format levels (applied unconditionally; shadPS4 gates them on SDK 2.50, which every PS5 title is), then always returns `NOT_CONNECTED`, so the camera never streams. Closes when: a host camera is exposed to guests.
- [sceCameraGetConfig, sceCameraSetConfig, sceCameraSetAttribute, sceCameraGetDeviceInfo, sceCameraGetFrameData and sceCameraIsValidFrameData](../../../core/libs/prx/libSceCamera/Export.cpp) (libSceCamera) - prototypes from orbital, answers and layouts (config 104 bytes, attribute 112, device info 16, frame data up to 584) from [shadPS4 camera_config.cpp and camera_device.cpp](https://github.com/shadps4-emu/shadPS4/tree/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/camera) without a camera, not measured on a console. As no frame ever arrives, GetFrameData marks both statuses invalid (0xFFFFFFFF) and returns `NOT_OPEN`, shadPS4's answer for a camera that never started. SetConfig, SetAttribute and GetDeviceInfo (once open) return `NOT_CONNECTED`; GetConfig writes shadPS4's default (type 1, YUV422 then Y8, 1280x800, 60 Hz) into both extensions.
