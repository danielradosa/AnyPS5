Behaviour that differs between LibreSSL versions throws: `SHA256` with a null digest buffer (older versions return a static buffer) and `SHA512_Final` with the SHA-512/224 or SHA-512/256 digest length. A failed key setup zeroes the key as current LibreSSL does (older versions leave it unchanged), and CTR leaves the last keystream block in `ecount_buf` even at a block boundary. Null pointers, other `rounds` values and a CFB or CTR position outside 0-15 throw
