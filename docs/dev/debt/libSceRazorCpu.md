# libSceRazorCpu technical debt

### Silent stubs

- [libSceRazorCpu](../../../core/libs/prx/libSceRazorCpu/Export.cpp): capture-controller registration, thread-local capture storage, marker serialization and flushing are not implemented. The host implements only the confirmed uninitialized-profiler path: markers return zero without reading labels, and `sceRazorCpuFlushOccurred` returns false without writing its optional output.
- [sceRazorCpuDisableFiberUserMarkers](../../../core/libs/prx/libSceRazorCpu/Export.cpp) (libSceRazorCpu) - `void(void)` from [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json) and [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Debug/RazorCpu.cs), which documents it as switching the marker context tag from the fiber to the thread. Markers are not recorded without a capture, so there is no tag to switch and it does nothing, like the [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/3a9f57265d28975658f1ca941daa5c879c7a74bd/src/core/libraries/razor_cpu/razor_cpu.cpp) stub
- [sceRazorCpuInitDataTags, sceRazorCpuShutdownDataTags, sceRazorCpuTagArray, sceRazorCpuTagBuffer, sceRazorCpuResizeTaggedBuffer, sceRazorCpuUnTagBuffer](../../../core/libs/prx/libSceRazorCpu/Export.cpp) (libSceRazorCpu) - prototypes from orbital and SharpProspero (the data sampler's buffer-tag table and its tags). Without a capture there is no data sampler: the storage passed to Init is neither read nor written, tags are not kept and every call returns 0, like the shadPS4 stubs. Error results for bad arguments, an Init without Shutdown or an UnTag of an unknown buffer are unknown
- [sceRazorCpuBeginLogicalFileAccess, sceRazorCpuEndLogicalFileAccess](../../../core/libs/prx/libSceRazorCpu/Export.cpp) (libSceRazorCpu) - prototypes `(filename, u64 tag, u64 size, u8 operation)` and `int(void)` from orbital and SharpProspero (operation 0 = read, 1 = write). Without a capture no file access is attributed, so both return 0 without reading their arguments, like the shadPS4 stubs; an End without a Begin also returns 0, which is unverified

- [sceRazorCpuJobManagerDispatch, sceRazorCpuJobManagerJob and sceRazorCpuJobManagerSequence](../../../core/libs/prx/libSceRazorCpu/Export.cpp): argument positions and serialized widths are recovered from machine instructions. Dispatch takes seven arguments, including two 64-bit payloads whose upper 16 bits are replaced by the count fields. The payloads are not dereferenced, so their original pointer-versus-integer types and the semantic names of the event identifiers remain unresolved. Job and Sequence serialize 16-bit identifiers and an event selector; their source enum names are unavailable.
- [sceRazorCpuGetDataTagStorageSize](../../../core/libs/prx/libSceRazorCpu/Export.cpp) (libSceRazorCpu) - `size_t(uint32_t tagCount)` from orbital and SharpProspero; the per-tag size of the console's table is unknown. Without a data sampler nothing is stored, so it returns 0 bytes for every count, the value the shadPS4 stub returns
