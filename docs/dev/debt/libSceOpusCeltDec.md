# libSceOpusCeltDec technical debt

### Functional

- [libSceOpusCeltDec](../../../core/libs/prx/libSceOpusCeltDec/Export.cpp) uses FFmpeg for 48000 Hz mono/stereo signed-16 decoding of CELT-only packets. It mirrors [libSceOpusDec](../../../core/libs/prx/libSceOpusDec/Export.cpp) (signatures, 640-byte opaque state and byte-count return follow [public PS5 decoder research](https://github.com/blackbearreloaded/ps5-hardware-audio-decoding/blob/26be5a12f92b2cdc67f8a9e082fd69ae0e9a35a2/docs/DECODING.md#direct-opus-abi) and [ProsperoRadio](https://github.com/blackbearreloaded/ProsperoRadio/blob/2c4029c3a8f43e9e1dfef98374d94d99b14d745d/src/opus_decoder.cpp)) with the production routing's CELT-only input contract: a packet TOC configuration below 16 (SILK or hybrid), an invalid code-3 frame count, and a packet above 120 ms throw, as [libSceOpusDec](../../../core/libs/prx/libSceOpusDec/Export.cpp) throws for its own invalid inputs. Console PCM equivalence and error codes are unverified, and the firmware's opaque state layout and error recovery are unknown; PPSA99001 reaches this decoder only as a fallback for a retryable libSceOpusDec error, which the general decoder here never returns
