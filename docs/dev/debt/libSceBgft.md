# libSceBgft technical debt

### Silent stubs

- [sceBgftServiceInit, sceBgftServiceIntInit, sceBgftServiceTerm, sceBgftServiceIntTerm](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - AnyPS5 has no background transfer service: `sceBgftServiceInit` and `sceBgftServiceIntInit` check their memory block and succeed without using it, `sceBgftServiceTerm` and `sceBgftServiceIntTerm` succeed, and none of them keeps state, so the other calls do not check initialization
- [sceBgftServiceDownloadStartTaskAll, sceBgftServiceDownloadPauseTaskAll, sceBgftServiceDownloadResumeTaskAll, sceBgftServiceDownloadStopTaskAll](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - succeed and do nothing: the host runs no downloads, so there is no task to start, pause, resume or stop

### Unknown function info

- [sceBgftServiceInit](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - the parameter block, a memory pointer, a 32-bit size and a reserved word that must be zero, and the 1 MiB minimum follow [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Platform/DownloadService.cs#L70-L85), which says the service rejects anything else; the PS4 [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/_types/bgft.h#L5-L9) layout, a pointer and a `size_t`, is the same for a block under 4 GiB. `sceBgftServiceIntInit` takes the same block in OpenOrbis ([Bgft.h](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/Bgft.h#L14)), the PS4 header; no PS5 source declares it, and it is checked as `sceBgftServiceInit` is. A null block or memory, a smaller size and a non-zero reserved word throw, as the console's codes for them are unknown. Whether the console lets a title start the service at all is not measured
- [sceBgftServiceIntTerm](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - the PS4 [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/Bgft.h#L15) header declares it without parameters next to `sceBgftServiceIntInit`; no PS5 source declares it. It ends the internal service as `sceBgftServiceTerm` ends the public one
- [sceBgftServiceDownloadStartTaskAll, sceBgftServiceDownloadPauseTaskAll, sceBgftServiceDownloadResumeTaskAll, sceBgftServiceDownloadStopTaskAll](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - the `int32_t (void)` signatures follow the PS4 [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/Bgft.h#L22-L28) header; no PS5 source declares them. The console's answer when no task exists is not measured
- [sceBgftServiceDownloadFindActivePatchTask, sceBgftServiceDownloadFindActivePupTask, sceBgftServiceIntDownloadFindActiveGameAndGameAcTask, sceBgftServiceIntDownloadFindActiveTask, sceBgftServiceIntDownloadGetGameAndGameAcProgress, sceBgftServiceIntDownloadGetPatchProgress, sceBgftServiceIntDownloadGetPlayGoProgress, sceBgftServiceIntDownloadGetProgress, sceBgftServiceIntDownloadGetTaskInfo, sceBgftServiceIntDownloadPauseTask, sceBgftServiceIntDownloadRegisterTaskByStorageEx, sceBgftServiceIntDownloadResumeTask, sceBgftServiceIntDownloadStopTask, sceBgftServiceIntDownloadStartTask and sceBgftServiceIntDownloadUnregisterTask](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceBgft.c), but no credible PS5 prototypes were found. - [sceBgftServiceDownloadFindTaskByContentId, sceBgftServiceDownloadGetProgress, sceBgftServiceDownloadStartTask, sceBgftServiceDownloadStopTask, sceBgftServiceDownloadPauseTask, sceBgftServiceDownloadResumeTask](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - the declarations follow [SharpProspero's DownloadService bindings](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Platform/DownloadService.cs).
