### Unknown function info

- [sceBgftServiceInit](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - the parameter block is a memory pointer and a 64-bit size. [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Platform/DownloadService.cs#L70-L85) declares it as a 32-bit size and a reserved word that must be zero, with a 1 MiB minimum, and says the service rejects anything else; the PS4 [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/_types/bgft.h#L5-L9) layout, a pointer and a `size_t`, is the same for a block under 4 GiB, so a size of 4 GiB or more is treated as a non-zero reserved word. `sceBgftServiceIntInit` takes the same block in OpenOrbis ([Bgft.h](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/Bgft.h#L14)), the PS4 header; no PS5 source declares it, and it is checked as `sceBgftServiceInit` is. A null block or memory, a smaller size and a non-zero reserved word throw, as the console's codes for them are unknown. Whether the console lets a title start the service at all is not measured
- [sceBgftServiceIntTerm](../../../core/libs/prx/libSceBgft/Export.cpp) (libSceBgft) - the PS4 [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/Bgft.h#L15) header declares it without parameters next to `sceBgftServiceIntInit`; no PS5 source declares it. It ends the internal service as `sceBgftServiceTerm` ends the public one
