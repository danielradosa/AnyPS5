# libSceVoiceQoS technical debt

### Silent stubs

- [sceVoiceQoSReadPacket](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - network voice packet streaming is not implemented: it returns 0 and writes size 0 (indicating no packet is available). Aliens: Fireteam Elite (PPSA03393) calls it on its startup path (`0x76D14C`-`0x76D16E`) and stops with `not implemented` if it throws
- [sceVoiceQoSWritePacket](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - network voice packet streaming is not implemented: it returns 0 leaving `*size` untouched (treating all input bytes as accepted). Aliens: Fireteam Elite (PPSA03393) sets `*size` to the packet size before `WritePacket` (`0x76CEB9`-`0x76CEC4`), compares `*size` against that input size upon return (`0x76CF07`-`0x76CF10`) to verify all bytes were accepted, and stops with `not implemented` if it throws

### Unknown function info

- [sceVoiceQoSInit](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - `0x804E0905` for a second initialization comes from [prosper](https://github.com/mattias800/prosper)'s reading of the module and was not measured: on a PS5 a valid call blocks inside a homebrew payload, so it never returns there. PPSA26344's two call sites (`0xE307BF`, `0x151C45D`) pass an allocated pointer, a 0x40000-byte block and app type 0x10000000. The app type and the block are not used: endpoints and connections are kept in host memory
- [sceVoiceQoSCreateLocalEndpoint, sceVoiceQoSDeleteLocalEndpoint, sceVoiceQoSCreateRemoteEndpoint, sceVoiceQoSDeleteRemoteEndpoint, sceVoiceQoSConnect, sceVoiceQoSDisconnect, sceVoiceQoSSetLocalEndpointAttribute, sceVoiceQoSGetLocalEndpointAttribute, sceVoiceQoSSetRemoteEndpointAttribute, sceVoiceQoSSetConnectionAttribute, sceVoiceQoSReadPacket, sceVoiceQoSWritePacket](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - the signatures are the PS4 prototypes in [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json) (32-bit ids, a local endpoint made from a user id and two device ids, attributes passed as id, value pointer and `int` size, packets as a data pointer and an in/out `unsigned int` size), the same as [fpPS4](https://github.com/red-prig/fpPS4/blob/04cefd43e6fddd1ab033e7980cd356d14c964905/src/ps4_libscevoice.pas#L97-L111) for the two calls it declares. PPSA10112 (Unreal Engine voice module) calls them that way: `CreateLocalEndpoint(&id, user, 0, 0)`, `Connect(&id, local, remote)`, `ReadPacket(connection, buffer, &size)` with a 0x2000 buffer, and treats a nonzero result as failure and -1 as no id; Aliens: Fireteam Elite (PPSA03393) calls `DeleteLocalEndpoint`, `CreateRemoteEndpoint`, `DeleteRemoteEndpoint`, `Connect`, `Disconnect`, the endpoint attribute calls and the packet calls with the same signatures (e.g. `0x76D132`, `0x76D16E`, `0x76CECB`). Nothing was measured on a console
- [sceVoiceQoSSetLocalEndpointAttribute, sceVoiceQoSGetLocalEndpointAttribute, sceVoiceQoSSetRemoteEndpointAttribute, sceVoiceQoSSetConnectionAttribute](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - attribute ids 0 to 8 are taken as MIC_VOLUME, MIC_MUTE, SPEAKER_VOLUME, SPEAKER_MUTE, DESIRED_OUT_BIT_RATE, MIC_USABLE, SILENT_STATE, REMOTE_MUTE and SPEAKER_DESTINATION, the order of [fpPS4](https://github.com/red-prig/fpPS4/blob/04cefd43e6fddd1ab033e7980cd356d14c964905/src/ps4_libscevoice.pas#L16-L25)'s list; PPSA10112 sets and reads 1 as a one-byte mute flag and reads 5 as a one-byte "microphone usable" flag. The four mute and usable flags must be one byte, the other attributes keep a value of any positive size, whose type is unknown, and give it back only for the same size. MIC_USABLE and SILENT_STATE are taken as read-only. Ids outside 0 to 8 throw, as does reading an attribute that is not a flag and was never set, since its default is unknown; flags read as 0 until set. Which attributes the console accepts on which object is unknown, so every object accepts every writable attribute; remote endpoint and connection attributes are stored but no exported call reads them
- [sceVoiceQoSCreateLocalEndpoint, sceVoiceQoSDeleteLocalEndpoint, sceVoiceQoSCreateRemoteEndpoint, sceVoiceQoSDeleteRemoteEndpoint, sceVoiceQoSConnect](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - error choices are not measured: every call answers `0x804E0901` (not initialized) before `sceVoiceQoSInit`, then `0x804E0902` (argument invalid) for a null pointer, a nonpositive attribute size, an unknown id or a user other than the logged-in one. Deleting an endpoint that a connection still uses answers `0x804E0907`, named RESOURCE_USED in the PS Vita firmware's error table ([vitasploit](https://github.com/Sorvigolova/vitasploit/blob/c93119ef30df11b08c8a6c4d1c7ca2ebe1443483/include/FW_200_320/errors.js#L1286-L1292), whose 0x804E0901, 0x804E0902 and 0x804E0905 match the PS5); when the console returns it is unknown. Ids are the lowest free non-negative number of their kind, no limit on endpoints or connections is enforced, the same pair can be connected more than once, and the device ids are not checked or used
- [libSceVoiceQoS firmware exports](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - `sceVoiceQoSGetRemoteEndpointAttribute`, `sceVoiceQoSGetConnectionAttribute` and `sceVoiceQoSGetStatus` follow public PS4 SDK prototypes in [Orbital](https://github.com/AlexAltea/orbital/blob/b321fcdbd700cc02da1cb1ad25412781d5ec73c6/tools/ida/db_types.json#L2436-L2441) and remain throwing stubs as endpoint and connection attribute storage is unverified on hardware. `sceVoiceQoSEnableChat`, `sceVoiceQoSDisableChat`, `sceVoiceQoSDebugGetStatus`, `sceVoiceQoSInitHQ`, `sceVoiceQoSSetMode`, and `sceVoiceQoSTerminate` are declared without parameters from the firmware export database (aerolib.csv); their guest signatures are unverified on hardware and every call throws

### Functional

- [sceVoiceQoSEnd](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - `0x804E0901` (not initialized) before any initialization was measured on a PS5 (firmware 13.60, #1407); ending an initialized library was not, because a valid `sceVoiceQoSInit` never returns inside a homebrew payload. PPSA14632 calls it at shutdown and PPSA26344 after a nonzero `sceVoiceQoSInit`. After an initialization it deletes every endpoint and connection, returns 0 and clears the init flag, so the library can be initialized again. Whether the console also ends the libSceVoice instance that its `sceVoiceQoSInit` starts ([prosper](https://github.com/mattias800/prosper)'s reading of the module), and whether it refuses to end while endpoints exist, is unknown
- [sceVoiceQoSReadPacket, sceVoiceQoSWritePacket, sceVoiceQoSGetLocalEndpointAttribute](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - no microphone is captured and no received voice is played: `sceVoiceQoSReadPacket` returns 0 with a size of 0 and leaves the buffer untouched, which PPSA10112 treats as no data, MIC_USABLE always reads 0, and `sceVoiceQoSWritePacket` accepts every packet and drops it, leaving the size untouched. Whether the console answers an empty read with 0 or with an error is unknown
- [sceVoiceQoSGetLocalEndpoint, sceVoiceQoSGetRemoteEndpoint](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - signatures follow [Orbital](https://github.com/AlexAltea/orbital/blob/b321fcdbd700cc02da1cb1ad25412781d5ec73c6/tools/ida/db_types.json#L2437-L2439) (`GetLocalEndpoint(connectionId, int* localId)` and `GetRemoteEndpoint(connectionId, int* remoteId)`). Operations look up the connection by allocated id and return the connected local or remote endpoint id; an unknown connection id or null output pointer returns `ARGUMENT_INVALID` (0x804E0902), and calling before initialization returns `0x804E0901`
