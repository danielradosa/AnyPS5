# libSceVideoRecordingP technical debt

### Silent stubs

- [libSceVideoRecordingP](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) has no recorder: `sceVideoRecordingQueryMemSize`, `sceVideoRecordingOpen` and their `2` forms (the [orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json) prototypes `sceVideoRecordingQueryMemSize2(const param*)` and `sceVideoRecordingOpen2(path, param, heap, int32_t heapSize)`, the same as the first forms) return `SCE_VIDEO_RECORDING_ERROR_UNSUPPORTED` (0x80A80008), so no recording is ever open. `sceVideoRecordingGetStatus` reports the recording state, which stays `SCE_VIDEO_RECORDING_STATUS_NONE` (0), and `sceVideoRecordingStart`, `sceVideoRecordingStop` and `sceVideoRecordingClose` return `SCE_VIDEO_RECORDING_ERROR_INVALID_STATE` (0x80A80006, named in [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/f510f9aef273f820d5ba12d78786008b66c817b2/src/core/libraries/video_recording/video_recording_error.h)) without a recording. The transitions an open recording would take (Start to running, 1; Stop from running to paused, 2; Close back to none, with the statuses from fpPS4) are assumed and cannot be reached. `sceVideoRecordingSetInfo` keeps the info only for `sceVideoRecordingGetInfo`
