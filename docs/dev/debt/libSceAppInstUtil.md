# libSceAppInstUtil technical debt

### Silent stubs

- [sceAppInstUtilInitialize, sceAppInstUtilTerminate](../../../core/libs/prx/libSceAppInstUtil/Export.cpp) (libSceAppInstUtil) - return success and keep no state: AnyPS5 has no install service to bring up, and the one installed application, the running title, needs none. A repeated `sceAppInstUtilInitialize` succeeds, as [SharpProspero's payload installer](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Payload/Services/AppInstaller.cs#L43-L57) initializes again before every install and stops at a non-zero result; the calls that query the service do not check it

### Unknown function info

- [sceAppInstUtilAppIsInUpdating, sceAppInstUtilAppGetSize, sceAppInstUtilAppInstallPkg, sceAppInstUtilAppPrepareOverwritePkg, sceAppInstUtilAppRecoverApp, sceAppInstUtilAppUnInstallAddcont, sceAppInstUtilAppUnInstallPat, sceAppInstUtilAppUnInstallTheme, sceAppInstUtilAppUnInstallTypes, sceAppInstUtilGetInstallProgressInfo, sceAppInstUtilGetInstallProgress and sceAppInstUtilGetPrimaryAppSlot](../../../core/libs/prx/libSceAppInstUtil/Export.cpp) (libSceAppInstUtil) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceAppInstUtil.c), but no credible prototype was found. They are declared without parameters only to resolve the known imports; this is not an ABI claim and callers must not call them until a prototype is verified. The other seven declarations follow [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/AppInstUtil/AppInstUtil.cs)
- [sceAppInstUtilAppExists](../../../core/libs/prx/libSceAppInstUtil/Export.cpp) (libSceAppInstUtil) - the `(const char* titleId, int32_t* exists)` signature follows [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/AppInstUtil/AppInstUtil.cs#L65-L77) and the PS4 [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/0a1aaf9dd4a92695538bdeb09fb056d06dd11725/include/orbis/AppInstUtil.h#L31) header, which write 0 or non-zero through a 32-bit output; SharpProspero's own [PackageInstaller](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Platform/PackageInstaller.cs#L278-L296) passes a one-byte output instead, so the console's output width is not settled. AnyPS5 runs one installed title, as for `sceSystemServiceLaunchApp`: the running title's ID from `param.json` exists (1) and any other ID, an empty or longer one included, does not (0). A null title ID or output throws, as the console's codes for them are unknown
- [sceAppInstUtilAppInstallAll, sceAppInstUtilAppInstallTitleDir, sceAppInstUtilAppUnInstall](../../../core/libs/prx/libSceAppInstUtil/Export.cpp) (libSceAppInstUtil) - throw: AnyPS5 installs and removes no applications, and the console's code for a title that is not installed is unknown
- [sceAppInstUtilAppIsInInstalling](../../../core/libs/prx/libSceAppInstUtil/Export.cpp) (libSceAppInstUtil) - no install pass ever runs, so it writes 0 through its output; a null output throws, as the console's code is unknown. The sources disagree on its signature: SharpProspero's [bindings](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/AppInstUtil/AppInstUtil.cs#L79-L88), followed here, take one output pointer, its [PackageInstaller](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Platform/PackageInstaller.cs#L477-L498) and OpenOrbis a title or content ID with the answer as the result
