- [sceAgcCbMemsetExclusive](../../../core/libs/prx/libSceAgc/Cb/src/Dispatch.cpp) (libSceAgc, NID `6nths4DHNrs`) - the signature `uint32_t* (SceAgcCb* cb, uint64_t destination, const void* pattern16, uint64_t sizeInBytes)` and the shape of what it writes follow [OpenAGC](https://github.com/OpenAGC/OpenAGC/blob/3c7e8072f0d7684e930454794fd5c02056946d73/src/cb_builders.c#L82-L142) ([test](https://github.com/OpenAGC/OpenAGC/blob/3c7e8072f0d7684e930454794fd5c02056946d73/tests/test_cb.c#L86-L147)), which places the builder in the library at 0x3100 and says it binds a compute shader of the library instead of writing DMA_DATA: 32 dwords, five SET_SH_REG packets (the program address, RSRC1 and RSRC2, RSRC3, the three thread counts and nine user-data registers) and a DISPATCH_DIRECT of 64-thread groups over `size / 16` blocks, returning the first packet. [prosper](https://github.com/mattias800/prosper/blob/a4e149f29c364ae34fd84740892422cc1705880d/prosper/tests/data/console_oracle/agcbuild.unmeasured.tsv#L48-L50)'s console probe, which passes a command buffer and five integers, faulted for all three of its argument patterns, as a dereference of the pattern pointer would. The console's shader, its code and its user-data layout are not public; OpenAGC binds a kernel of its own, and so does this builder: the nine-instruction kernel in `Dispatch.cpp` takes `(s8 << 6) + v0` as the block index and stores the pattern in s4 to s7 with `buffer_store_format_xyzw` through the buffer descriptor in s0 to s3 (the destination as base, a 16-byte stride, the block count as `num_records`, format 0x4b), which the driver runs as a [buffer fill](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Memory/BufferFill.cpp) or recompiles. The program address, RSRC1 (1, five VGPRs in wave64), RSRC2 (eight user SGPRs and the group id in s8), RSRC3 (0), the user data (the descriptor, the pattern and 0 in `COMPUTE_USER_DATA_8`) and the header flags (0, as `sceAgcCbDispatch` writes them, where OpenAGC sets bit 0) therefore differ from the console's packets; their number, order and sizes and the dispatch are OpenAGC's. OpenAGC returns null for a null command buffer or pattern and for fewer than 32 free dwords, without calling the buffer's callback; here, as in the other builders, the callback is asked for space and a null buffer, a null pattern or a buffer that stays short throws. A null, misaligned (not 16-byte) or above-48-bit destination, a size that is not a multiple of 16 and more than 2^32 - 1 blocks also throw, as the console's answer is unknown; a size of 0 writes the packets with a dispatch of no groups
